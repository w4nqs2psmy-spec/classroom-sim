# materials/ — jigsaw-moodin lukukappaleet

Kolme lukua poimittu tiedostosta `docs/cooperative-leadership-2009.pdf`
(Asko Leppilampi, "Cooperative leadership", 24 s.) build-aikaisesti
pdfjs-distillä — sama periaate kuin `scripts/extract-doc.ts`:ssä:
poiminta tapahtuu kerran, committoitu teksti on ainoa ajonaikainen lähde.

| Kappale | Tiedosto | Artikkelin luku |
|---|---|---|
| a | `cooperative-leadership-in-action.txt` | "Cooperative leadership in action" (s. 7–10) |
| b | `cooperative-development-of-a-work-community.txt` | "Cooperative development of a work community" (s. 10–12) |
| c | `good-meeting-practises.txt` | "Good meeting practises as an example of cooperative leadership" (s. 12–16) |

Tekstit ovat englanniksi (lähdeartikkelin kieli); jigsaw-moodin agentit
keskustelevat niistä suomeksi. Jokainen lukija näkee vain oman
kappaleensa (`src/jigsaw/prompts.ts`).
