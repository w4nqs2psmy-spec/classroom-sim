# classroom-sim — CSCL classroom simulation

Five AI student agents (Vilma, Otto, Nea, Sami, Leo) + a teacher run collaborative
learning tasks (Ideation → Evaluation → Synthesis). Built for live keynote/workshop
use: the presenter steers which task the group works on and a dynamics layer makes
the group phenomena (participation, interaction structure, conflict/consensus)
visible on a projector.

## What's built and verified

**Stage 1 — agent core (`src/`, FROZEN — do not modify without explicit user approval)**
- Node 24 native TS, no build step; only runtime dep is `@anthropic-ai/sdk`.
- Haiku 4.5 for routine turns, Opus 4.8 for teacher evaluation only (`src/model-routing.ts`).
- Structured outputs everywhere; JSONL session logs in `logs/` with per-turn `costUSD`
  (~$0.21–0.26/session); `--dry-run` runs the loop with a mock client.
- **Cache invariant:** the static world block in `src/prompts.ts` is padded to ≥4,096
  Haiku tokens (~4,198). Never trim below that — prompt caching silently stops.

**Stage 3 — React UI (`ui/`, Vite + React 19; only runtime deps: react, framer-motion)**
- Reducer store (`store.tsx`) + synchronous per-render agent derivation
  (`computeAgents` — never route per-agent state through dispatch+effect; a
  one-render lag breaks AnimatePresence).
- Downtime mode (free CSS ambient + scripted "meaningful moments", `downtime.ts`),
  task mode with autoplay, session replay of real Stage 1 logs via read-only Vite
  dev middleware (`sessionLoader.ts` — path-traversal-guarded, never spawns runs).
- Presentation mode (`usePresentationMode` — fullscreen w/ CSS fallback, dimming,
  `PresentationBar`).
- **Dynamics layer** (`dynamics.ts`, pure function of the visible turn prefix):
  participation bars, who-addresses-whom SVG arcs anchored to `SEATS`, dialogue-move
  climate timeline with click-to-seek, rule-based insight chips (free-rider,
  socio-cognitive conflict, convergence, working-in-silos, false-consensus).
  Hand-tagged `dialogueMove` = exact; everything heuristic is styled as estimated
  (faint arcs, faded ticks) — never dress estimation up as ground truth.
- **SVG character visuals** (`Character.tsx` + `characterConfig.ts`): static lineup
  built; expression/gaze/emphasis steps are PARKED awaiting the user's verdict on
  the look (aesthetic gate).
- **Task library + command layer** (built 2026-07-04):
  - `ui/src/tasks.ts`: four hand-scripted tasks, each authored against an
    `InteractionProfile` — lapland (open/negotiated), divide-solve (divisible/silos),
    dilemma (forced choice/false consensus), jigsaw (high interdependence).
    Verified structurally via `computeDynamics` assertions, not vibes.
  - `ui/src/commands.ts`: single `CommandEnvelope` contract; every steering surface
    (hotkeys 1-4/Space/D/P in presentation mode, `PresenterDock`, future QR audience
    relay) dispatches through it; external surfaces post to
    `BroadcastChannel("classroom-sim-commands")`. Unknown task ids are rejected.
  - `keepPlaying` on `START_TASK` preserves playback across mid-run task switches.
- **In progress:** optional per-task SOURCE DOCUMENTS (PDF → build-time extracted
  text via `scripts/extract-doc.ts`, committed JSON in `ui/src/source-docs/`,
  source panel in WorkspacePanel, citation markers in the timeline). Stage-1
  injection is a documented contract only (cached-prefix block), not built.

## Locked decisions (do not re-litigate)

- **Execution model: scripted, pre-tuned task datasets.** Zero API calls in the UI;
  stage reliability beats live generation. Real Stage 1 sessions are replayed from
  logs, never generated by the UI.
- **Tasks must change HOW the group works, not just the topic** — turn-taking,
  participation balance, consensus mode, interdependence — and the difference must
  be measurable in `computeDynamics` output within ~5 turns.
- **One command-layer contract** (`commands.ts`) for all steering; a future
  QR/audience vote posts the same envelopes with zero refactor.
- **Stage 1 stays frozen** (confirmed 3×). Designed-but-not-built additive changes
  are documented in code comments (`dialogueMove` self-report field; source-document
  cached-prefix block).
- **All content in English** (confirmed 5×; recurring "Finnish" notes in briefs are
  template leftovers). Character names stay as-is.
- **Zero new runtime dependencies** without explicit justification; build-time
  devDeps acceptable when never bundled (e.g. `pdfjs-dist` for PDF extraction).
- Cost badge separates **measured** (log `costUSD`) from **estimated** (`~` prefix);
  never blend the two silently.

## Recurring gotchas

- **Restart the Vite dev server after structural refactors** before diagnosing UI
  "bugs" — stale HMR state caused three false alarms (ghost bubbles, hook-order
  errors).
- Rapid programmatic turn-stepping (<300 ms/turn) makes AnimatePresence exits
  batch-flush late — benign, not a leak; real pacing (2–7 s) is unaffected.
- Dataset switches must reset `turnIndex` BEFORE swapping turns (the
  `handleSelectDataset` path is crash-hardened; reuse it).
- Cost booking is gated on `sessionLoading` so an async session swap can't book the
  outgoing dataset's turns.

## Public deployment (GitHub Pages)

Live at **https://w4nqs2psmy-spec.github.io/classroom-sim/** — repo
`w4nqs2psmy-spec/classroom-sim`, served from the `gh-pages` branch (path `/`),
auto-detected/enabled by GitHub on first push of that branch.

**Static-mode design** (`vite.config.ts` has `base: "./"`; `sessionLoader.ts`
has try/catch fallbacks in `listSessions()`/`fetchSession()`): on a static host
with no dev middleware, session listing/loading falls back to the one curated
log shipped as a static file at `ui/public/sessions/` (see `CURATED_SESSION` in
`sessionLoader.ts`), and `postAgentReply` (live interjection replies) gets a
fast 404 → returns `null` → the caller uses the per-agent i18n fallback line.
Both paths were verified end-to-end via `vite preview` (serves `dist/` with NO
dev middleware — the closest local approximation of Pages) before every deploy.

**To redeploy after changes:**
```sh
npx vite build --config ui/vite.config.ts
# from a scratch/temp dir, NOT the main worktree (avoids touching your branch):
git worktree add --detach /tmp/gh-pages-deploy
cd /tmp/gh-pages-deploy && git checkout --orphan gh-pages && git rm -rf . >/dev/null
cp -r <repo>/ui/dist/. .
git add -A && git commit -m "Deploy: <what changed>"
git push origin gh-pages   # history accumulates turn by turn; no --force needed
cd - && git worktree remove --force /tmp/gh-pages-deploy
```
Propagation is usually near-instant but can take a minute or two; re-check with
`curl -s -o /dev/null -w "%{http_code}" https://w4nqs2psmy-spec.github.io/classroom-sim/`.
